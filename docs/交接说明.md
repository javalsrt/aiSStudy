## 二、本轮已完成的功能

### 1. 作息设置
- 范围选择可视化：默认作息 / 按班级配置（年级分组、整组全选、实时计数）
- 多班级批量保存，同一事务内覆盖配置并重算已排课时间
- **图片识别**：本地 OCR（OpenCV 版式切分 + RapidOCR），整图单次识别约 2.7s；视觉大模型兜底
- **各班作息方案概览**：时间相同的班级自动归为一组，标记「自定义」，点击班名可直接编辑
- 保存内联反馈（`已保存 · N 个节次 · 同步 M 条课表`）+ 变更记录

### 2. 校园信息（AI 底层知识库）
- 管理端增删改查、启停、排序
- **一键导入新规**：支持 `.docx`（WPS/Word 另存）、`.txt`、`.md`；标题智能识别；同标题自动更新
- 导入**不需要选分类**，系统按内容自动归类（奖助/就业升学/教学管理/生活服务/规章制度/校园概况）
- 保存防重复提交 + 内联「已保存（时间）」
- **规定概览**：总数/启用/停用、分类分布（点击筛选）、最近更新
- **变更记录**：新增/修改/删除/导入/启停，含操作人与时间

### 3. 请假 / 临时外出
- 学生申请：事由、去向、出校/回校时间、告知家长（必填）、家长电话
- 返校打卡：定位 + 拍照上传
- 审批权级：`≤3 天` 班主任；`>3 天` 班主任初审 → 校级领导终审；临时外出班主任审批
- 审批人身份留痕（班主任 / 教导主任 / 管理员），管理端按班级分组展示

### 4. 人员与职务
- `teacher.duty`（教师/班主任/教导主任）、`teacher.is_leader`、`class_info.head_teacher_id`
- 人员管理标签页：**教师管理 / 学生管理 / 教师职务 / 班干部设置**
- 班主任设置：班级搜索、年级筛选、紧凑网格、更换、**取消班主任**、调整记录
- 班干部：班长/副班长/团支书/学习委员/纪律委员/生活委员/文娱委员/体育委员/心理委员/宣传委员/劳动委员/课代表
- 权限：管理员可设任意职务；教师仅可为本人班级学生设置班干部
- 两类调整记录：`class_head_log`、`student_position_log`

### 5. AI 助手（App 底栏第 5 项，页面级 Tab）
- 分层回答：校规知识 → 班主任/领导组织信息 → 课程 RAG → 个人数据（SQL，仅查本人）→ 通用
- 可回答：「我的班主任是谁」「X 班班主任是谁」「请假超过三天找谁批」
- 同问题 60 秒缓存，命中限流时友好提示
- 输入区：透明背景、无免责小字；**语音输入已按要求撤销**

### 6. 其他
- 课程管理列表改卡片行布局，右下角显示「第 X / Y 页」
- 人员管理表格精简（专业/年级合并、行高压缩）
- App 通讯录：领导（琥珀）/班主任（蓝）/职称（灰）/班干部（绿）徽标，卡片阴影与更大留白
- 聊天未读水位线（`chat_read_state`）、调课通知按学生可见、教师通知按课程聚合

## 四、服务器部署

```bash
cd ~/aiSStudy && git pull

for f in 17-bell-class 18-bell-change-log 19-school-info 20-leave-request \
         21-school-info-log 22b-teacher-duty-safe 23b-user-position-safe 24-duty-adjust-log; do
  docker exec -i znxsgl-mysql mysql -uroot -p123456 --default-character-set=utf8mb4 \
    znxsglTest < init-db/$f.sql
done

docker compose up -d --build backend ocr nginx
```

部署后浏览器 **Ctrl+Shift+R** 强刷；App 安装根目录新 APK。

## 五、关键配置

| 变量 | 说明 |
|---|---|
| `DEEPSEEK_API_KEY` | AI 助手必需 |
| `VISION_API_KEY` / `VISION_URL` / `VISION_MODEL` | 可选，OCR 失败时兜底（默认硅基流动 Qwen2.5-VL） |
| `OCR_SERVICE_URL` | 容器 `http://ocr:8100`；本地 `http://localhost:8100` |
| `OCR_AUTO_START` | 容器 `false`（用独立 ocr 容器）；本地默认 `true` |
| `OCR_PORT` / `OCR_PYTHON` | 本地 OCR 端口与 Python 命令 |

> ⚠️ `JWT_SECRET` 曾被误截断，已修复。服务器重建后**旧 token 全部失效**，所有账号（含 App）需重新登录一次。
