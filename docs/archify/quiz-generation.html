App 出题模块架构

并行拆分题型 · 单飞锁 · Redis 共享缓存 · question_bank 预生成题库

说明：本 HTML 是出题模块架构的可视化预览，源数据见 docs/archify/quiz-generation.architecture.json。

并行拆分题型

  • 单选 7、判断 3、解析 3、填空 2
  • 四路任务同时调用大模型
  • 总耗时约等于最慢题型，不再串行等待

单飞锁

  • 同一 cacheKey 只允许一个生成任务
  • 其他请求共享同一个 Future 结果
  • 避免多学生同时点击时重复调 AI

Redis 共享缓存 + 题库

  • Redis 多实例共享，TTL 24 小时
  • question_bank 表持久化，重启不丢
  • Redis 不可用时自动降级本地缓存

预生成题库

  • 章节导入 / AI 生成成功后自动触发
  • 后台预生成难度 1~3
  • 支持手动接口 POST /api/quiz/bank/prewarm
  • 定时任务默认关闭，可配置凌晨执行

内容变化自动失效

  • cacheKey 包含章节和课时内容版本
  • 章节内容更新后生成新 key
  • 避免返回旧题
