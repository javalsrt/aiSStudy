# 中职自适应答题 App · 答题界面与出题设计（全专业）

> 版本：v1.0　范围：10 个大类、78 个专业　目标：一套答题壳，覆盖全部专业

---

## 0. 一句话方案

**答题页面只有一套壳，题目由"内容块"拼装；78 个专业收敛为 5 类页面模板。** 新增专业只加配置，不改界面。

之所以不做 78 套页面：中职专业课的差异不在"界面长什么样"，而在"题干里放什么"——符号、图纸、流程、数据、案例。把这五种东西做成可插拔的内容块，差异就被吸收掉了。

---

## 1. 三条设计原则

1. **界面稳定，内容变化。** 学生每次答题看到的是同一个结构：进度、题干、图形区、作答区、操作栏。换专业只换题干里的块。
2. **图形一律"服务端出图，客户端看图"。** 大模型不画图，只输出结构化描述；服务端渲染成 PNG/SVG。客户端只做缩放、全屏、热点标注。这样图纸、几何图、统计图、电路图共用一个查看器。
3. **出题按"认知动作"分级，不按"难中易"分级。** 一档是"指认/复述"，二档是"解释/按规程操作"，三档是"诊断/排障/迁移"。这样不同专业都能落地。

## 2. 答题页面总结构（所有专业共用）

```
┌──────────────────────────────────────────┐
│  ←     单选题        3/15   [进阶]  02:14 │  顶部状态栏
├──────────────────────────────────────────┤
│  题干文字（可含行内公式）                  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  内容块区：公式 / 图纸 / 表格 /     │  │  题干卡（可滚动）
│  │  流程图 / 案例材料                  │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ○ A  选项文字                            │
│  ○ B  选项文字                            │  作答区
│  ○ C  选项文字                            │
│  ○ D  选项文字                            │
│                                          │
├──────────────────────────────────────────┤
│  [草稿纸]        [不会]        [提交]      │  底部操作栏
└──────────────────────────────────────────┘
```

**固定规则**

- 顶部只放 4 个信息：题型、进度、难度徽标、计时。不再加其他标签。
- 题干卡是唯一可滚动区域，选项区不滚动；长题（图纸/案例）滚动题干，保证选项始终可见。
- 图形块右下角固定"全屏"按钮；全屏后可双指缩放、拖动。
- 填空题输入框上方的工具条：符号键盘、草稿纸、清空。
- 测评模式不即时判对错；练习模式选完立即给对错和一句解析。

**难度徽标**：`基础` / `进阶` / `挑战`，对应 1 / 2 / 3 档。连续答对时轻提示一次，不弹窗。

## 3. 五类页面模板

### 模板 A · 符号式

**适用**：数学、化学、电子、电工、化工工艺、计算机类（代码）

**页面差异**：题干卡里出现"公式块 / 化学式块 / 代码块"，填空题带符号键盘。

```
题干：下列化学方程式书写正确的是（  ）
┌ 公式块 ────────────────────────────────┐
│  A.  H₂ + O₂ —点燃→ H₂O                │
│  B.  2H₂ + O₂ —点燃→ 2H₂O              │
└────────────────────────────────────────┘
○ A   ○ B   ○ C   ○ D
```

**内容块**

| 块 | 用途 | 渲染方式 |
|---|---|---|
| 行内公式 | 题干里的变量、单位 | LaTeX `$...$` |
| 公式块 | 独立成行的方程、反应式 | 居中 LaTeX |
| 化学式 | H₂SO₄、Ca²⁺ | Unicode 上下标优先 |
| 代码块 | 程序阅读、命令 | 等宽字体 + 高亮 |
| 符号键盘 | 填空输入 π √ ² ³ ∠ △ ℃ Ω | 自定义九宫格 |

**出题规则**

- 一道题只考一个公式或一个概念，不叠加。
- 化学式统一由后端"化学式规范化器"处理：`H2SO4 → H₂SO₄`，`Ca2+ → Ca²⁺`。
- 反应条件写在箭头上方，用文本模板 `—(浓硫酸, 170℃)→`，不依赖 mhchem。
- 计算题必须给单位和有效数字要求；填空答案支持等价形式（`0.5` = `1/2`）。
- 代码题只考"读代码选输出 / 选错误行"，不考手写完整程序。

**判分**：选择精确匹配；填空做等价归一化（去空格、统一分数小数、统一单位）。

---

### 模板 B · 图纸式

**适用**：工业机器人、数控、模具、机电、电气、供用电、制冷、智能设备、建筑、市政、道桥、装配式、测量、汽修、新能源、车身修复、飞机维修、无人机、园林、植保（图片识别）

**页面差异**：题干卡里出现"图纸块"，占屏幕 40%~60%，可全屏。

```
题干：图示机构中，构件 ③ 的名称是（  ）
┌ 图纸块 ────────────────────────────────┐
│   [ 机构运动简图 SVG ]          ⤢ 全屏  │
│      ① —— ② —— ③                      │
└────────────────────────────────────────┘
○ A 曲柄   ○ B 连杆   ○ C 滑块   ○ D 机架
```

**内容块**

| 块 | 用途 |
|---|---|
| 图纸块 | 装配图、零件图、电路图、系统图、平面图、解剖图 |
| 热点标注 | 图上可点的圆形序号，题目引用序号 |
| 表格块 | 公差表、材料表、参数表 |

**出题规则**

- 一张图只问一个点；多个考点拆成多题。
- 图必须有图号和 caption，题干用"图示"引用，不复述图上已有信息。
- 识图题优先级：零件名称 → 符号含义 → 尺寸/公差 → 工序顺序 → 故障位置。
- 图纸来源优先级：题库资产（真实图纸）> 服务端按 DSL 生成的简图。**大模型不直接生成图片。**
- 禁止出"图中未标注但需要专业知识猜测"的题。

**判分**：与符号式相同，选择题为主。

---

### 模板 C · 流程式

**适用**：护理、中医护理、烹饪、面点、酒店、旅游、轨道交通运营、高铁乘务、航空服务、应急救援、养老、畜禽、水产、种植、园艺、中草药、农机维修、农产品加工、制糖、造纸、冶炼、服装工艺、美发、美容

**页面差异**：题干卡里出现"步骤块"——编号步骤，允许缺一步。

```
题干：混凝土浇筑的正确工序是（  ）
┌ 步骤块 ────────────────────────────────┐
│  ① 模板湿润   ② 分层浇筑                │
│  ③ 振捣       ④ ?                       │
└────────────────────────────────────────┘
○ A 养护  ○ B 拆模  ○ C 验收  ○ D 切缝
```

**内容块**

| 块 | 用途 |
|---|---|
| 步骤块 | 工序、护理流程、服务流程、处置流程 |
| 图片块 | 操作示意、成品图、病灶图 |
| 表格块 | 参数表、配比表、时间表 |

**出题规则**

- 流程题只考三类：**排序**（做成选择）、**找错步**、**补缺步**。
- 步骤不超过 6 步，超过则拆题。
- 涉及安全/禁忌的步骤优先出判断题（"该操作可以直接进行"）。
- 情景题给一个具体场景（"客人投诉上菜慢"），不考抽象定义。

**判分**：选择、判断精确匹配；填空写步骤名，允许同义词（"振捣" = "捣实"）。

---

### 模板 D · 数据式

**适用**：会计、工程造价、电商、跨境、物流、国际商务、市场营销、直播电商、大数据、农产品检测、水产养殖（水质）、纺织（参数）

**页面差异**：题干卡里出现"表格块 / 单据块"，填空以数值为主。

```
题干：根据下列凭证，该笔业务的借方金额为（  ）
┌ 单据块 ────────────────────────────────┐
│  日期      摘要        金额             │
│  3-01     采购原料    12,000           │
│  3-02     支付运费       800           │
└────────────────────────────────────────┘
○ A 12,000   ○ B 12,800   ○ C 800   ○ D 11,200
```

**内容块**

| 块 | 用途 |
|---|---|
| 表格块 | 报表、清单、台账、参数表 |
| 单据块 | 凭证、发票、运单、合同（图片 + 关键字段） |
| 统计图片块 | 柱状、折线、饼图（服务端渲染） |

**出题规则**

- 数据只给必要行，不超过 6 行 4 列。
- 计算题必须能口算或一步列式，不考复杂运算。
- 表格里的干扰数据要有意义（考"该看哪一行"），不随机堆数据。
- 金额、单位、百分号统一格式，答案带单位。

**判分**：填空做数值归一化（去千分位、统一单位、允许小数位差）。

---

### 模板 E · 文本式

**适用**：法律事务、治安管理、幼儿保育、运动训练、智慧养老、旅游、酒店、航空服务、美容、美发、平面设计、动漫、数媒、音乐舞蹈、工艺美术、广告设计

**页面差异**：题干卡里出现"案例块 / 材料块"，以情景判断为主。

```
题干：幼儿在园内发生磕碰，教师首先应当（  ）
┌ 案例块 ────────────────────────────────┐
│  户外活动时，一名幼儿奔跑摔倒，膝盖破皮。 │
└────────────────────────────────────────┘
○ A 通知家长   ○ B 立即处理伤口并上报
○ C 继续活动   ○ D 让幼儿自己休息
```

**内容块**

| 块 | 用途 |
|---|---|
| 案例块 | 情景材料、法条摘录、客户对话 |
| 图片块 | 作品图、仪容对比图、动作示范图 |
| 术语高亮 | 题干中的专业术语加粗或下划线 |

**出题规则**

- 案例 80 字以内，只保留与答案相关的信息。
- 判断题考"规范/禁忌"，选择题考"下一步做什么"。
- 法律类必须给法条依据或教材原话，不考个人观点。
- 设计/艺术类不考主观审美，考"构图原则、色彩关系、软件操作"等可判定内容。

**判分**：选择、判断精确匹配；填空考术语，允许同义表述。

## 5. 出题引擎设计

### 5.1 题目数据结构

```json
{
  "type": "单选",
  "template": "B",
  "knowledgeId": 1024,
  "difficulty": 2,
  "stem": [
    { "type": "text", "value": "图示机构中，构件 ③ 的名称是：" },
    { "type": "figure", "src": "fig/mech-03.svg", "caption": "图 1 机构运动简图" }
  ],
  "options": ["曲柄", "连杆", "滑块", "机架"],
  "answer": "连杆",
  "distractors": {
    "曲柄": "混淆了主动件与从动件",
    "滑块": "把移动副构件当成连杆",
    "机架": "把固定件当成运动构件"
  },
  "explanation": "构件 ③ 两端均为转动副且不固定，为连杆。"
}
```

- `stem` 是块数组，旧字段 `question` 保留，前端优先读 `stem`。
- `distractors` 是可选的诊断信息，用于选项层自适应。
- `template` 由专业配置决定，不由模型自由选择。

### 5.2 按范式出题，不按专业出题

后端维护一张**专业配置表**：

| 字段 | 说明 |
|---|---|
| `majorCode` | 专业代码 |
| `template` | A/B/C/D/E |
| `blockWhitelist` | 允许的内容块 |
| `typeRatio` | 选择/判断/填空 配比 |
| `termDict` | 本专业术语表 |
| `assetDir` | 图纸/图片资产目录 |

Prompt 只写 5 套（对应 5 个模板），专业差异通过配置注入。这样 78 个专业维护成本可控。

### 5.3 题型配比建议

| 模板 | 选择 | 判断 | 填空 | 理由 |
|---|---|---|---|---|
| A 符号式 | 6 | 3 | 6 | 计算和公式填空多 |
| B 图纸式 | 7 | 4 | 4 | 识图以选择为主 |
| C 流程式 | 5 | 4 | 6 | 步骤名适合填空 |
| D 数据式 | 5 | 3 | 7 | 算数值适合填空 |
| E 文本式 | 6 | 5 | 4 | 情景判断多 |

### 5.4 三档难度（按认知动作定义）

| 档位 | 认知动作 | 题目特征 | 示例问法 |
|---|---|---|---|
| 1 基础 | 指认、复述、匹配 | 答案在教材原文或图上 | "图示部件是" |
| 2 进阶 | 解释、比较、按规程操作 | 需要一步推理或记住流程 | "应先进行哪一步" |
| 3 挑战 | 诊断、排障、迁移 | 给异常现象定原因，跨知识点 | "最可能的原因是" |

### 5.5 自适应四层

1. **课程难度**：沿用现有 3 档，连续两次同向才升降。
2. **知识点掌握度**：每个知识点维护 0~1 的 mastery，答对加分、答错扣分，下一题优先从最低 mastery 的知识点抽。
3. **选项诊断**：学生选错哪个干扰项，就记录对应误区；同一误区连续出现两次，推送一道针对性题。
4. **错题回流**：错题知识点权重提升，连续答对两次后降权。

**题型配比也自适应**：判断连续错，就提高判断题比例；填空连续错，就降低填空题比例并增加同知识点的选择题。这是"只有三种题型"时最能体现自适应的地方。

### 5.6 让学生看见自适应

- 顶部难度徽标随档位变化。
- 连续答对 2 题时，题干卡顶部出现一行轻提示："连续答对，下一题难度提升"。
- 交卷报告里写清升降档原因："本次升档：正确率 87%、零跳过、平均 42 秒/题"。
- 报告页给知识点热力图，红色知识点直接对应"下一步学什么"。

## 7. 验收标准

- 同一套答题界面，能在 5 个模板专业下正常显示，无布局错乱。
- 图纸类题目可全屏、可缩放、热点可点。
- 化学式、公式无红字乱码。
- 填空题等价答案判定正确（`0.5` 与 `1/2`、`12,000` 与 `12000`）。
- 连续答题后难度档位按规则变化，且报告能看到变化原因。
- 新增一个专业只需加配置，不改客户端代码。
