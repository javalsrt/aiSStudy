## 1. 项目是什么

面向中职学校的「智慧校园 + AI 学习」平台，一套后端服务四个客户端。

| 模块 | 目录 | 技术栈 | 端口 | 启动方式 |
|---|---|---|---|---|
| 后端 | `backend/` | Spring Boot 3.2.0 + MyBatis-Plus + Security(JWT) + WebSocket，**JDK 17** | 8080 | IDEA 运行 `ZnxsglApplication` |
| 学生 App | `android/` | 原生 Java + ViewPager2 + Markwon + Retrofit，**JDK 17**，compileSdk 34 / minSdk 26 | — | Android Studio / `gradlew assembleDebug` |
| Web 管理端 | `web-admin-react/` | React 18 + TypeScript + Vite + Tailwind + Radix UI + Recharts | 5174 | `npm run dev` |
| 官网 | `website/` | 纯静态 HTML/CSS/JS | 5500 | 后端自动拉起或任意静态服务器 |
| 小程序 | `miniapp/` | uni-app（Vue3） | — | HBuilderX / `npm run dev:mp-weixin` |
| OCR 服务 | `ocr-service/` | Python FastAPI + RapidOCR | 8100 | 后端自动拉起 |
| Embedding 服务 | `embedding-service/` | Python + BGE-M3 | 8000 | 后端自动拉起 |

> 默认情况下启动后端会顺带拉起 OCR、Embedding、官网、管理端 dev（见 `application.yml` 的 `ocr.auto-start`、`embedding.local.auto-start`、`frontend.local.*`）。容器部署时用 `FRONTEND_LOCAL_AUTO_START=false` 关闭。

**数据库：** MySQL 8.0，库名 `znxsglTest`，本地默认 `root / 123456`（3306）。建表与种子数据在 `init-db/`，按编号顺序执行。
**Redis：** 本地默认关闭（`APP_REDIS_ENABLED=false`），此时幂等/限流走内存实现；服务器上置 `true`。

### 环境变量

| 变量 | 说明 |
|---|---|

| `DB_USERNAME` / `DB_PASSWORD` | 默认 root / 123456 |

## 3. 核心业务规则（改对应模块前必读）

### 3.1 排课与课表

1. `dayOfWeek` 取值 **1–7**（1=周一，7=周日）。一键自动排课只排 1–5；手动调课/导入允许周日（节日补课场景）。
2. `schedule` 表按「学生 × 课程 × 周次」拆成独立记录，才能支持按周调课。
3. 排课必须同时校验 **班级、教师、教室** 三个维度无冲突；教室容量不足时回退普通教室。
4. 跨周调课走手工流程：取消原周格 → 切换目标周 → 选新格 → 确认，后端事务内删除+新建。
5. 调课界面保持**原表格弹窗**流程，不要新增「锁定调课」概念（用户明确否决过）。
6. 课程删除会级联删除：该班排课记录、课程-班级关联、仅该班使用的专属课程（公共课保留）。
7. 学期未配置（如 `2026-2027-1`）时不要执行一键排课。

### 3.2 课程导入

1. 导入后课程自动设为上架（`status=1`），并立即为学生写入 `schedule`。
2. 重复导入用 `ensureCourse` 优先复用班级已存在的**同名课程**，不要只按「课程名+教师」匹配（历史 bug：AI 识别教师名不一致会产生同名不同 `course_id` 的冗余课程）。
3. 学生端查询课程接口按课程名去重，同名只返回一条。
4. Excel 校验：星期 1–7、非空、班级存在、行数上限等；批量导入学生只支持「学号+姓名」表头。

### 3.3 权限

1. `user.role` 与 `sys_user_role` 必须同时维护。历史上缺关联会导致所有用户 403（如 `chapter:view`），修复方式是按 `user.role` 回填 `sys_user_role`。
2. 教师账号通过 `teacher.real_name` 与 `user.real_name` 完全一致绑定。
3. 免登录白名单（`SecurityConfig`）：图片预览与文件下载接口，含 `/uploads/**`、`/api/chat/download-file`。新增文件下载接口记得加白名单，否则 App 图片 404。

### 3.4 通知与聊天

1. App 聊天默认只发消息，**只有包含 `@AI` / `@ai` 才触发 AI 回复**。
2. 考试/作业通知三重去重：内存缓存 10 分钟（`examId_userId`）→ 数据库预查 → `chat_message` 唯一索引 `uk_user_biz(user_id, biz_type, biz_id)`。
3. 调课通知按「课程:班级:原时段->新时段:教室:原因」为 key，5 分钟内同一操作只发一次。
4. WebSocket 推送按用户级去重：60 秒内同类型同内容只推一次。
5. 插入新排课通知前，先删除该课程该学生 `sender_role='teacher'` 且内容含【课程通知】/排课已更新/课程「 的旧通知。
6. 教师通知铃铛：不显示自己发的消息；不显示当前正在查看的课程群消息；点击通知立即本地清未读并调后端标记已读。
7. `ChatMessageMapper` 已读状态要覆盖三类：通知/教师回复/AI 回复、其他学生公开聊天、@当前学生。

### 3.5 AI 出题

1. 多个题型**并行**调用 LLM；每种题型每批最多 5 题。
2. 结果缓存 15 分钟，key 为参数 MD5 指纹（科目/上下文/题型/难度/数量）。
3. 章节上下文截断到 4000 字符。
4. 出题走 `QuestionGenerationService.getOrGenerate(...)`，由 `QuizController.doGenerate` 调用；异步任务 + 前端 2 秒轮询（`taskId`），不是同步等待。

## 4. 正在进行的任务：答题界面科目主题化 + FunctionPlotView 扩展

### 4.1 已确认的问题（务必先修）

**C1（阻断性）：数学题的图像永远不会出现。** 出题实际走 `QuestionGenerationService.buildTypePrompt()`（约 196–206 行），该 prompt **没有 graph 指令**；同时 `QuestionGenerationService.parseQuestions()`（约 227–271 行）也**没有透传 `graph` 字段**。而 `QuizController.buildAdaptivePrompt()`（约 392–426 行）和 `QuizController` 自己的 `parseQuestions()`（约 467–491 行）是有 graph 的。两处断链导致前端 `FunctionPlotView` 形同虚设。

修复点：
1. 在 `buildTypePrompt()` 的「要求」里补充：仅当题目适合用函数图像表达时输出 `"graph":"y=..."`（支持分号分隔多条曲线），并写进 schema 示例；
2. 在 `QuestionGenerationService.parseQuestions()` 中照抄 `QuizController` 的 graph 透传逻辑；
3. 抽查一次出题结果，确认 JSON 里有 graph 且 App 能画出来。

### 4.2 科目主题方案（A 线）

**目标**：让不同科目在界面上有身份，而不是全部白底蓝字一个样。

1. **A1 新建 `SubjectThemes.java`**（建议 `com.znxsgl.student`）：
   - `Theme { int accent; int accentSoft; String emoji; String[] cheers; }`
   - `get(String subject)`：公共课精确匹配（语文/数学/英语/思想政治/历史/心理健康/体育与健康/信息技术），专业课按关键词兜底（艺术/设计/动漫/室内 → 品红系；机电/汽车/数控 → 石墨蓝；财经/商贸/物流/金融 → 琥珀；计算机/网络 → 青蓝；其余 → 默认蓝）。
2. **A2 答题页头部**：主题色低饱和弥散渐变（参考测试页 `AuroraHeaderView` 的写法，蓝绿为主，避免大面积紫）+ 科目图标 + 科目名 + 随机鼓励语。
3. **A3 控件联动**：题型徽章 `tv_quiz_tag`、选项字母圆徽标、选中态、判断题双按钮、进度点，统一取主题色；`QuizPagerAdapter` 通过构造参数或 `setTheme()` 注入，颜色用 `GradientDrawable` 动态生成（现有代码已有该模式）。

### 4.3 FunctionPlotView 扩展方案（B 线）

现有能力：单条 `y=f(x)`、固定 x∈[-10,10]、y 自适应、递归下降解析器（`+ - * / ^`、括号、sin/cos/tan/asin/acos/atan/sqrt/abs/ln/log/exp、pi/e、隐式乘号）、断点检测、不可交互。

**一期（兼容现有 graph 字符串）：**
1. **B1 多函数**：`graph` 用 `;` 分隔多条曲线（如 `y=x^2;y=2x-3`），每条从主题色系调色板取色；`normalize()` 需按分号切片后分别解析。
2. **B2 手势**：双指缩放、单指平移、双击重置。注意控件在 `ViewPager2` 内，`onTouchEvent` 里必须 `getParent().requestDisallowInterceptTouchEvent(true)`，否则横滑会被当成翻页（填空题输入框已有同款处理）。
3. **B3 解析器扩展**：`|x|` 绝对值、`floor/ceil/sign`（可组合成分段函数）、`tau` 常量。
4. **B4 入场动画**：曲线 400ms 从左到右描绘（`PathMeasure` + `getSegment` 裁剪），网格淡入；`onDetachedFromWindow` 停止动画。

**二期（graph 升级为 JSON，旧格式自动兼容）：**

- `param`：参数方程（椭圆、圆、摆线）
- `bar` / `pie`：统计图

## 5. 硬性约束与踩坑清单

### 5.1 安全与数据

| 约束 | 说明 |
|---|---|
| 密码必须 BCrypt | 不支持 MD5 登录 |
| JWT secret ≥ 32 字节 | 修改后全部旧 token 失效 |
| 敏感配置走环境变量 | API Key、数据库密码禁止明文入库 |
| 关键业务必须事务 | 排课、调课、导入、删除级联 |
| 异常必须带上下文日志 | 禁止 `catch (Exception ignored)` 静默吞异常 |
| 幂等 | 重复提交接口用 `requestId`，5 分钟去重窗口 |
| 限流 | AI 接口必须有限流，防刷 |
| 文件存储 | 规划为云对象存储（OSS），本地 `.uploads/` 仅开发用 |

### 5.2 后端

1. **改后端必须重启** `ZnxsglApplication` 才生效；未映射的新路径会被全局异常处理成 500，看起来像 bug。
2. 实体/表结构变更要同步 `init-db/` 脚本，不能只在代码里加字段。
3. 课程管理等列表接口避免 N+1，批量 SQL；排课高频查询字段必须建索引。
4. 启动日志已精简：root 级别 WARN，只保留警告/错误和一行就绪摘要，不要随意加 INFO 日志。
5. 服务器部署：`docker compose up -d --build backend ocr nginx`；管理端 `index.html` 为 no-store，浏览器需 Ctrl+Shift+R。

### 5.3 Android

1. **Material BottomNavigationView 最多 5 个 item**，第 6 个会启动即崩。加 Tab 必须替换旧 Tab。
2. `ViewPager2` 内的输入框/可滑动控件要 `requestDisallowInterceptTouchEvent(true)`，否则会出现「能输入但退格删不掉」。
3. 文本答案回显：先移除 `TextWatcher` 再 `setText`，并 `setSelection(len)`；文本未变化时不要重复 `setText`（会与输入法状态失步）。
4. 列表弹窗操作后刷新用 `setTimeout` 延后，避免状态更新竞态。
5. 底部导航毛玻璃：`GlassNavBackgroundView` 为 0.12 降采样静态磨砂，300ms 节流，不要逐帧截屏；导航用 `translationZ` 压在上层，答题全屏时同步淡出。
6. 启动页：`windowSplashScreenAnimatedIcon` 用透明占位图；启动图标无白底/无内边距；不要加底部加载点动画。
7. 课表 7 列：`DAY_NAMES`、表头循环、课程格渲染、日期高亮都要覆盖 1–7；改完需重新打 APK 才可见。
8. 学习界面卡片使用 4 种饱和色循环、白色粗体标题、底部深色信息条、错层纸片效果；左侧章节时间线宽度 18dp。

### 5.4 管理端

1. 批量导入学生：全屏遮罩 + 加载动画 + 成功/失败明细横幅；结果存 `sessionStorage` 30 分钟，跨页面返回仍可见；只有 ≥1 条成功才刷新列表。

## 6. 常见故障速查

| 现象 | 排查方向 |
|---|---|
| 接口 403（如 `chapter:view`） | `sys_user_role` 是否缺失，按 `user.role` 回填 |
| 新接口 500 / 404 | 后端是否重启，路径是否被安全配置拦截 |
| App 课表不显示周日 | 后端是否重启；APK 是否为 7 列版本 |
| 图片/附件打不开 | `/uploads/**`、`/api/chat/download-file` 是否在白名单 |
| 学生收不到考试通知 | 三重去重是否误判；`uk_user_biz` 是否已写入 |
| 调课通知重复 | 通知 key 与 5 分钟窗口；WebSocket 60 秒去重 |
| 管理端页面 500 | 对应 `init-db` 迁移是否执行（请假/职务/校园信息） |
| 出题很慢/超时 | 并行题型、每类 5 题、上下文 4000 字限制是否被改坏 |
| 数学题没有函数图 | 见第 4.1 节 C1，prompt 与 parse 两处断链 |
| 课程重复出现同名 | `ensureCourse` 是否复用同名课程；学生端是否按课程名去重 |
