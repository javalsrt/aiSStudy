## 学生请假申请流程

学生因病因事需要离校，应当在离校前通过「智学职达」App 提交请假申请，流程为：填写申请 → 班主任初审 → 超过 3 天由校级领导终审 → 审批通过后离校 → 返校当天打卡销假。申请提交后可在 App「我的 → 请假申请」中查看审批进度、审批人身份与审批意见，审批期间如需撤回可点击「取消申请」。请假未获批准前不得擅自离校，未经批准离校按旷课处理。因突发疾病、家庭紧急情况来不及事前申请的，应先电话或短信告知班主任，返校后 24 小时内补办手续并在事由中注明「事后补办」。

## 请假审批权限与办理时限

请假 3 天以内（含 3 天）由本班班主任审批，班主任应在收到申请后当天完成审批。请假超过 3 天的，先由班主任初审，初审通过后自动转入校级领导（教导主任、副校长等）终审，两级均通过方为批准。临时外出原则上当天往返，由班主任一级审批即可。班主任因公外出无法及时审批时，由校级领导或管理员代为审批，审批系统会记录审批人身份（班主任 / 教导主任 / 副校长 / 管理员）。审批人驳回申请时必须说明理由，学生可修改后重新提交。

## 请假申请填写要求

提交申请时须如实填写请假事由、离校去向、出校时间与预计回校时间，并勾选「已告知家长」、填写家长联系电话，未告知家长的不予审批。病假应写明就诊医院或症状，事假应写明具体事由，参加比赛、考试等公务活动应写明活动名称与组织单位。预计回校时间必须晚于出校时间，跨天请假按实际天数计算，系统会自动折算天数并据此判断审批层级。提供虚假事由或冒用他人名义请假的，一经查实按校纪处理并记入诚信记录。

## 返校打卡与销假规定

请假批准后，学生返校当天须在 App 中完成「返校打卡」，打卡需同时提交实时定位与现场照片，两者缺一不可。打卡成功后申请状态变为「已返校」，班主任与校级领导可在管理端「请假审批 → 已处理」中查看打卡时间、定位坐标与打卡照片。返校后未在规定时间内打卡的，视为未按时销假，班主任应联系学生及家长核实情况。确因特殊原因无法按时返校的，应在预计回校时间前再次提交续假申请，不得先逾期后补假。

## 临时外出（当天往返）规定

临时外出指当天离校、当天返校的短期外出，如上医院、购买生活用品、办理证件等，原则上不影响正常上课。办理时选择「临时外出」类型，填写事由与去向，由班主任审批。外出期间应保持手机畅通，返校后同样需要定位拍照打卡销假。临时外出不得连续多次申请规避请假审批，一学期内临时外出异常频繁的，班主任应约谈学生并通报家长。

## 请假期间的安全与考勤要求

请假期间学生的人身安全由学生本人及家长负责，应遵守交通与治安法规，不得前往危险区域，不得从事与申请事由无关的活动。请假期间如行程变更，应主动向班主任报告。请假到期未返校且未办理续假的，按旷课累计处理，累计旷课达到学校规定的，按学籍管理规定给予相应处理。班主任应建立请假台账，对长期病假、频繁请假的学生进行跟踪关怀。

## 请假常见问题解答

问：请假超过三天要找谁审批。答：先由本班班主任初审，初审通过后由校级领导（教导主任或副校长）终审，两级都通过才算批准。问：怎么知道我的请假批到哪一步了。答：在 App 中打开「请假申请」，每条记录右上角显示当前状态，下方显示初审与终审的审批人身份及意见。问：批假后忘了打卡怎么办。答：应尽快补打卡并向班主任说明情况，超过规定时间未打卡的由班主任核实后处理。问：可以代人请假吗。答：不可以，请假必须由学生本人账号提交，紧急情况可先由家长联系班主任，事后由学生本人补办。问：临时外出需要家长同意吗。答：需要，所有外出类申请都必须勾选已告知家长并填写家长联系电话。
